## Variants

| Type | Description | Use Case |
|------|-------------|----------|
| 4-Digit | Four individual input boxes | Short verification codes, PINs |
| 6-Digit | Six individual input boxes | Standard OTP, two-factor authentication |

## Anatomy

| # | Element | Description |
|---|---------|-------------|
| 1 | Title | Label text with optional icon (e.g. "Enter OTP") |
| 2 | Helper Text (Top) | Right-aligned hint above the inputs |
| 3 | Input Boxes | Individual single-character inputs with 8px gap |
| 4 | Subtext | Left-aligned helper text below inputs |
| 5 | Helper Text (Bottom) | Right-aligned helper text below inputs |

---

## Sizes

| Size | Height | Use Case |
|------|--------|----------|
| Large | 100px | Prominent OTP entry, onboarding flows |
| Medium | 96px | Default for most verification screens |
| Small | 88px | Compact layouts, inline verification |

---

## States

| State | Description | Visual |
|-------|-------------|--------|
| Default | Resting state, ready for input | Neutral border (#CCC), white background |
| Hover | Pointer over input box | Slightly emphasized border |
| Active | Currently being typed into | Highlighted border |
| Focused | Keyboard focus on input | Black focus ring (2px shadow) |
| Disabled | Input not available | Reduced opacity, grey background |
| Ghost | Skeleton/loading placeholder | Solid grey background (#EDEDED), no border |

## Styles

| Style | Border Color | Text Color | Use Case |

- Auto-advance focus to the next box after each digit
- Support paste to fill all boxes at once

- Show a resend option with a cooldown timer
- Do not mask OTP digits — they are already temporary

## Accessibility

| Requirement | Guideline |
|-------------|-----------|
| Semantic HTML | Use `<input>` elements within a `role="group"` container |
| aria-label | `"One-time password"` on the group container |
| aria-describedby | Link to instructions or error text |
| inputmode | `numeric` — shows numeric keyboard on mobile |
| autocomplete | `one-time-code` — enables OTP autofill |
| Keyboard: Tab | Navigate between input boxes |
| Keyboard: Backspace | Clear current and move to previous box |
| Focus ring | 2px visible shadow, ≥ 3:1 contrast |
| Text contrast | ≥ 4.5:1 against background (WCAG AA) |

## Developer Handoff

```tsx
interface OTPFieldProps {
  type?: '4-digit' | '6-digit';
  size?: 'large' | 'medium' | 'small';
  style?: 'default' | 'success' | 'error' | 'info';
  title?: string;
  titleIcon?: boolean;
  helperTextTop?: string;
  subtext?: string;
  helperTextBottom?: string;
  value?: string;
  onChange?: (value: string) => void;
  onComplete?: (value: string) => void;
  autoFocus?: boolean;
  disabled?: boolean;
}
```

```tsx
// Default 4-digit OTP
<OTPField
  type="4-digit"
  title="Enter OTP"
  subtext="Check your SMS"
  autoFocus
  onComplete={handleVerify}
/>

// 6-digit with error state
<OTPField
  type="6-digit"
  style="error"
  title="Verification Code"
  helperTextTop="Expires in 5:00"
  subtext="Invalid code, please try again"
  value={otp}
  onChange={setOtp}
/>

// Success confirmation
<OTPField
  type="4-digit"
  style="success"
  title="OTP Verified"
  subtext="Code accepted"
  disabled
/>
```
